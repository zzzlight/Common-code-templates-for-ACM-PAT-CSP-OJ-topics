# Plantillas de código comunes para temas de ACM, PAT, CSP, OJ
## Prefacio
**Nota: Este repositorio incluye algunas fórmulas matemáticas LaTeX insertadas en texto Markdown. Se recomienda usar el navegador Google Chrome e instalar el complemento [MathJax Plugin for Github](https://chrome.google.com/webstore/detail/mathjax-plugin-for-github/ioemnmodlmafdkllaclgeombjnmnbima) para visualizarlo; de lo contrario, no se podrá renderizar LaTeX.**

Las plantillas de código adjuntas en este repositorio son las más utilizadas que he resumido durante mi proceso de resolver problemas. La mayor parte del código está escrita por mí mismo como **interfaces C++ basadas en la sintaxis C++11**, por lo que se ajusta bastante a mi estilo de código. Las explicaciones y comentarios no son muy extensos. Creé este repositorio principalmente para hacer un resumen y poder usarlo en el futuro; también lo iré actualizando y corrigiendo con frecuencia. Por supuesto, si consideras que algunos de estos códigos también te son útiles, puedes usarlos directamente. Sin embargo, si no estás acostumbrado a mi estilo de código, es posible que te resulte un poco incómodo. Si tienes algún problema o detectas errores en mi código, no dudes en dejar un comentario en los `Issues` ღ( ´･ᴗ･` ) ¡un abrazo!
